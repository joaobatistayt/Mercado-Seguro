## 📖 Contexto e Justificativa

O projeto nasceu de uma necessidade urgente no **Sítio Jerimum** (Zona Rural de São João do Rio do Peixe - PB). A proprietária do **Mercadinho Jerimum** foi vítima de duas tentativas de assalto recentemente. Embora os bens tenham sido recuperados, o trauma alterou drasticamente a rotina do comércio:

- **Insegurança e Medo:** A comerciante passou a viver com medo constante, instalando grades em todo o estabelecimento.
- **Impacto Econômico:** O fechamento precoce das portas e o atendimento limitado através de grades derrubaram o faturamento e as vendas.
- **Dilema de Risco:** Sem uma alternativa tecnológica, os clientes eram atendidos pela grade (desconforto) ou precisavam ficar trancados dentro do mercado com a proprietária (risco compartilhado).

> 📰 A gravidade da situação na região é confirmada por registros da imprensa local: [PM frustra assalto e recupera bens na zona rural de São João do Rio do Peixe](https://www.diariodosertao.com.br/noticias/policial/736371/video-pm-frustra-assalto-e-recupera-dois-carros-e-grande-quantia-em-dinheiro-na-zona-rural-de-sao-joao.html)

## 🚀 A Solução

O **Mercado Seguro** atua como uma camada de proteção digital, permitindo que a comerciante atenda **de portas fechadas**. O diferencial é a **Identificação Preventiva**: o cliente não apenas faz o pedido, mas identifica seu veículo e horário antes de chegar ao local.

### Fluxo de Funcionamento
```
[Catálogo] → [Identificação] → [WhatsApp Dinâmico] → [Entrega Segura]
```

| Etapa | Descrição |
|-------|-----------|
| 🛒 **Catálogo** | O cliente escolhe os produtos via interface web. |
| 🪪 **Identificação** | O cliente informa obrigatoriamente o horário de retirada e a descrição do veículo (cor/modelo). |
| 💬 **WhatsApp Dinâmico** | O JavaScript processa o carrinho e gera um link estruturado com todos os dados (Pedido + Total + Veículo) direto para o WhatsApp da comerciante. |
| ✅ **Entrega Segura** | A comerciante prepara o pedido e só realiza a entrega ao visualizar o veículo correspondente ao agendamento. |

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido focando em **leveza e rapidez de carregamento** para zonas rurais com conexão limitada, utilizando apenas tecnologias nativas:

| Tecnologia | Uso |
|------------|-----|
| **HTML5** | Estrutura semântica da plataforma |
| **CSS3** | Estilização responsiva e interface do "Semáforo de Status" |
| **JavaScript (Vanilla)** | Lógica do carrinho, manipulação do DOM e integração com a API do WhatsApp via URLs dinâmicas |

> Nenhuma dependência externa. Zero frameworks. Máxima compatibilidade.
